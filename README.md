# Nexus Dev Lab ✳

Site demonstrativo responsivo criado para experimentar design de interfaces e interações na web.

## Funcionalidades

- Tema claro e escuro, com preferência salva no navegador
- Painel com abas: Visão geral, Terminal e Elementos
- Filtros de projetos por categoria
- Cartões com janelas de detalhes
- Botão para copiar o endereço do site
- Layout responsivo para computadores e celulares

## Tecnologias

HTML5, CSS3 e JavaScript puro, com fontes DM Sans e Space Grotesk.

## Executar localmente

Clone o repositório:

```bash
clear
git clone https://github.com/Kingnike1/nexus-lab-demo.git
cd nexus-lab-demo
```

Abra `index.html` no navegador. Não é necessário instalar dependências.

## Publicar na Vercel

1. Acesse https://vercel.com/new.
2. Importe `Kingnike1/nexus-lab-demo`.
3. Escolha **Framework Preset: Other**.
4. Mantenha o diretório raiz `./` e publique.

O código está no GitHub, mas a publicação na Vercel é uma etapa separada.

## Observação

Os cartões Nexus Share, Digital Vault e Meu Financeiro são conceitos demonstrativos neste site, não sistemas funcionais.
